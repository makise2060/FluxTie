# FluxTie 底栏交互优化方案（基准：Bettbox）

> 参考：[appshubcc/Bettbox](https://github.com/appshubcc/Bettbox)（Flutter 的 Mihomo/Clash 代理客户端，FlClash 系）。
> 其底栏被公认为比 fluxdo 更顺滑。本文拆解其技术构成，并给出 Jetpack Compose（Material 2 基座）的移植方案。
> 只移植设计与工程手段，不移植代码。

---

## 一、结论先行

Bettbox 的"顺滑"不是某个黑科技，而是**五件事的组合拳**：

1. **纯交叉淡化 + 不对称曲线**：页面切换 300ms，新页 `easeOutCubic` 快速淡入、旧页 `easeInCubic` 加速淡出——无位移、无缩放、无回弹，体感"干脆"；
2. **悬浮胶囊底栏**（`google_nav_bar`/GNav 5.0.7）：圆角 36 的浮动条，选中项 pill 从左到右"擦开"，文字只在动画最后 10% 才浮现（`pow(t, 13)`），兄弟项零抖动；
3. **状态全局外置**：切 tab 即改一个全局状态值，页面随便销毁重建，业务状态零丢失、零重新加载——"快"且"无感"；
4. **点击瞬间触感反馈**（`HapticFeedback.selectionClick()`，双保险注册）+ **动画期防连点锁**；
5. **独立重绘层**：整栏包 `RepaintBoundary`，栏的动画不波及页面重绘。

GNav 包本身没有物理引擎、没有特殊魔法——**可移植性极高**。

## 二、Bettbox 实现拆解（关键文件）

| 部分 | 实现 |
|---|---|
| 栏本体 | `lib/widgets/google_bottom_nav_bar.dart` 封装 GNav：悬浮 Stack 布局（`Positioned(bottom:0)` 盖在内容上，非 Scaffold.bottomBar） |
| 视觉 | 不透明 `surfaceContainer`、borderRadius **36**、左右 16 / 距底 12dp、1px `outlineVariant` 描边（亮 α0.5 / 暗 α0.4）、**双层阴影**（blur30/offset10/α0.08 + blur10/offset2/α0.04） |
| 选中动画 | GNav：250ms；pill 背景 `AnimatedContainer` 变色 + `Align(widthFactor: t)` 分数宽度裁剪展开；图标色 `easeInExpo`/`easeOutCirc`；文字 α = `pow(t,13)`；pill 背景色 primary@α0.20(亮)/0.26(暗) |
| 页面切换 | `lib/pages/home.dart` `_HomePageView`：`AnimatedSwitcher(300ms, easeOutCubic/easeInCubic, 纯 FadeTransition)`，同时只挂载当前一页；页面用 `GlobalObjectKey(PageLabel)` 保 key |
| 状态 | 全局 Riverpod provider（`controller.dart:1406 toPage`：popUntil 根 + 改 provider 值，**切 tab ≠ 路由跳转**） |
| 防遮挡 | 内容区底部预留 `84dp + (底部inset - 12dp)`（`constant.dart:55`），各页 scrollview 加此 padding |
| 其他 | `RepaintBoundary` 包栏；桌面端 `jumpToPage` 瞬移不补间；`enableNavBarHapticFeedback` 设置开关默认开 |

## 三、FluxTie 现状诊断

当前实现（`ui/page/main/MainPage.kt` + `NavigationComponents.kt`）：

- **内容切换是硬切**：`LazyLoadHorizontalPager` + `userScrollEnabled=false`，点击 tab 走 `pagerState.scrollToPage(index)`——瞬时跳变，无任何过渡动画；
- **底栏是标准 M2**：`BottomNavigation` + `BottomNavigationItem`，无标签（`alwaysShowLabel=false`）、选中变色是瞬间的（无 pill/指示器动画）、无触感反馈、贴边直角栏（divider 1.5dp + `navigationBarsPadding`）；
- **加分项（保留）**：`rememberAnimatedVectorPainter` 选中图标有方向感的小动画；`BackHandler` 回第一 tab；再点当前 tab 触发 `GlobalEvent.Refresh`；badge 支持；宽屏自动切 NavigationRail/Drawer（`MainNavigationType`）。

差距：Bettbox 的顺滑 = 内容过渡 + 指示器动画 + 触感 + 悬浮材质，FluxTie 目前一项都没有。

## 四、移植方案（Compose / M2 基座）

### P0 交互层（顺滑感的核心，建议先做）

**1. 内容切换：`AnimatedContent` 纯 fade 替代 pager 硬切**

```kotlin
// MainPage.kt：替换 LazyLoadHorizontalPager
val saveableStateHolder = rememberSaveableStateHolder()
AnimatedContent(
    targetState = currentPosition,                 // 当前 tab index
    transitionSpec = {
        (fadeIn(tween(300, easing = CubicBezierEasing(0.215f, 0.61f, 0.355f, 1f)))    // easeOutCubic 入
            togetherWith fadeOut(tween(300, easing = CubicBezierEasing(0.42f, 0f, 1f, 1f)))) // easeInCubic 出
            .using(SizeTransform(clip = false))
    },
    modifier = Modifier.fillMaxSize(),
) { page ->
    saveableStateHolder.SaveableStateProvider(navigationItems[page].id) {
        navigationItems[page].content()
    }
}
```

- `SaveableStateProvider`（key=tab id）对齐现状：LazyColumn 滚动位置、ViewModel 状态在切换后完整保留；
- 移除 pager 后 `BackHandler`、`GlobalEvent.Refresh`（onReselected）逻辑不变；
- 注意：`currentPosition` 要用"目标 index 立即生效"的状态（现在 `pagerState.currentPage` 改为普通 `mutableIntStateOf`）。

**2. 底栏：GNav 风格悬浮胶囊条（自绘，约 150 行）**

```kotlin
@Composable
fun FloatingBottomNav(current: Int, onChange: (Int) -> Unit, items: ImmutableList<NavigationItem>) {
    Surface(                                   // RepaintBoundary 等价：隔离重绘
        shape = RoundedCornerShape(36.dp),
        color = ExtendedTheme.colors.bottomBarSurface,
        border = BorderStroke(1.dp, ExtendedTheme.colors.divider.copy(alpha = 0.5f)),
        shadowElevation = 0.dp,
        modifier = Modifier
            .padding(horizontal = 16.dp)
            .graphicsLayer {                   // 双层阴影用 shadow+ambient 模拟
                shadowElevation = 12.dp.toPx()
                shape = RoundedCornerShape(36.dp)
                clip = false
            }
    ) {
        Row(Modifier.padding(horizontal = 8.dp, vertical = 10.dp)) {
            items.forEachIndexed { i, item -> NavPill(selected = i == current, item, onClick = {...}) }
        }
    }
}

@Composable
fun NavPill(selected: Boolean, ...) {
    val progress by animateFloatAsState(        // pill 宽度分数展开
        if (selected) 1f else 0f,
        animationSpec = tween(250, easing = FastOutSlowInEasing)
    )
    val haptic = LocalHapticFeedback.current
    Row(
        modifier = Modifier
            .clip(RoundedCornerShape(24.dp))
            .background(if (progress > 0f) ExtendedTheme.colors.primary.copy(alpha = 0.20f * progress) else Transparent)
            .clickable {
                haptic.performHapticFeedback(HapticFeedbackType.TextHandleMove)  // selectionClick 等价
                onClick()
            },
    ) {
        Icon(...)
        // 文字分数宽裁剪"擦入"，且 alpha=progress^3 只在末段浮现
        Box(Modifier.layout { measurable, _ ->
            val w = measurable.maxIntrinsicWidth(0)
            val placeable = measurable.measure(Constraints.fixedWidth((w * progress).roundToInt()))
            layout(placeable.width, placeable.height) { placeable.place(0, 0) }
        }) {
            Text(label, Modifier.alpha(progress * progress * progress))
        }
    }
}
```

- 悬浮布局：MainPage 的 `bottomBar` 改为 `Box { content; Column { Spacer(权重占位); FloatingBottomNav() } }` 或保留 `MyScaffold.bottomBar` + 栏外留 12dp 底距（`Modifier.navigationBarsPadding().padding(bottom = 12.dp)`）；
- **防遮挡**：内容底部 padding = `84.dp + (导航条inset - 12.dp).coerceAtLeast(0)`（对齐 Bettbox 公式），避免最后一条 feed 被浮栏盖住；
- **保留现有资产**：`rememberAnimatedVectorPainter` 图标动画、badge、`navigationItems` 数据结构、宽屏 Rail/Drawer 分支全部不动——只换 BOTTOM_NAVIGATION 分支的渲染；
- **兼容 `liftUpBottomBar` 偏好**：该开关现控制底栏上浮，悬浮条天然就是"上浮"形态——开关语义改为"悬浮胶囊条 / 传统贴底栏"二选一（传统栏保留现实现兜底，零风险回退）。

**3. 细节**
- 防连点：栏内 250ms 内忽略重复点击（`remember { mutableLongStateOf }` 时间戳，同 `ActionItem` 现有模式）；
- 暗色/AMOLED：pill 背景 α 提到 0.26；`bottomBarSurface` 走 `ExtendedTheme.colors`，AMOLED 下为纯黑描边加深——色板不新增字段，用现有 `bottomBar/card/divider` 组合。

### P1 视觉打磨（可选）
- 双层阴影精调（`BlurMaskFilter` 或双层 Box 模拟，M2 无 multi-shadow 原生支持，一层 12dp 已足够）；
- 选中图标微放大（`1f → 1.1f` spring）叠加现有 vector 动画。

### P2 不做 / 后议
- 横滑切 tab：Bettbox 移动端明确禁用横滑（`NeverScrollableScrollPhysics`），FluxTie 现状也禁用——**保持禁用**，避免与贴吧页内横向内容（图片九宫格等）手势冲突；
- 液态玻璃/毛玻璃：GNav 也是不透明纯色，无 BackdropFilter，不引入。

## 五、改动清单与验收

| 文件 | 改动 |
|---|---|
| `ui/page/main/NavigationComponents.kt` | 新增 `FloatingBottomNav`/`NavPill`；原 `BottomNavigation` 保留为传统模式 |
| `ui/page/main/MainPage.kt` | pager → `AnimatedContent + SaveableStateHolder`；bottomBar 分支接悬浮条；内容底部 padding 公式 |
| `res/values/strings.xml` | `liftUpBottomBar` 摘要文案更新（悬浮/传统二选一） |

验收：
- [ ] 切 tab 有 300ms 交叉淡化，无白屏、无布局跳动；
- [ ] 每个 tab 的滚动位置/加载状态切换后保留；
- [ ] 选中 pill 展开 250ms，文字末段浮现，兄弟项不抖；
- [ ] 点击有触感反馈，动画期连点不重启动画；
- [ ] 悬浮条不遮挡 feed 最后一条（留 84dp+inset）；
- [ ] 明/暗/AMOLED 三态 + 宽屏 Rail 分支正常；
- [ ] `liftUpBottomBar=false` 可回退传统贴底栏。
